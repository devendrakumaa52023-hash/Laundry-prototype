1. Create a new GitHub repo (github.com/new).
2. Upload everything in this folder, INCLUDING the hidden .github folder.
3. Go to the Actions tab > "Build APK" > wait ~3-5 min.
4. Open the finished run > Artifacts > download BiznisKing-APK (zip) > unzip > app-debug.apk.
5. Copy the APK to your phone and install (allow "install unknown apps").
